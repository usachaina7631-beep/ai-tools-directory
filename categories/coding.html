Coding tools

GitHub Copilot Paid

AI pair programmer that suggests code, writes tests and explains errors inside your editor.

Best for: Code suggestions while you type — speeds up people who already know how to code.

Tags: Code Completion, IDE · Official website: https://github.com/features/copilot

Cursor Freemium

AI-first code editor that edits whole files from instructions and answers codebase questions.

Best for: An AI code editor that understands your whole project — for serious builders.

Tags: Editor, Codebase Chat · Official website: https://www.cursor.com

Replit Freemium

Browser-based coding platform with an AI agent that helps build and deploy apps quickly.

Tags: Build Apps, Deploy · Official website: https://replit.com

Devin Desktop Freemium

AI code editor from the team behind Devin — the successor to Windsurf and Codeium, with agentic multi-file editing and smart autocomplete.

Tags: Code Editor, Agents · Official website: https://devin.ai/desktop

v0 by Vercel Freemium

Describe a UI in words and get working React components you can refine and ship.

Tags: UI Generation, React · Official website: https://v0.app

Bolt.new Freemium

Prompt-to-app builder by StackBlitz — describe an app in words and get a working full-stack web app with hosting, ready to edit and deploy.

Best for: Building the first version of a full website or app just by describing it — no coding needed.

Tags: App Builder, Full-Stack, Deploy · Official website: https://bolt.new

Frequently Asked Questions

Which coding tools here are free to start?

Five of the 6 coding tools have free plans: Cursor, Replit, Devin Desktop, v0 by Vercel and Bolt.new. GitHub Copilot is the only paid-only coding tool in this list.

Which tool writes code while I type?

GitHub Copilot. It is listed as best for code suggestions while you type — it speeds up people who already know how to code.

Can I build an app without coding?

Yes. Bolt.new builds the first version of a full website or app just by describing it — no coding needed. v0 by Vercel turns a UI described in words into working React components, and Replit's AI agent helps build and deploy apps quickly.

Which coding tool understands my whole project?

Cursor. It is listed as best for serious builders — an AI code editor that understands your whole project, edits whole files from instructions and answers codebase questions.
